# Botmatch harness (mods/game/aaa_botmatch). The harness exposes TWO
# distinct bot kinds. The kind is stamped at spawn time and is
# visible in /sl_bots list output, the player_information synthetic
# record (version_string), and the in-world nametag for mob bodies.
#   * "stub" — headless Lua state, no engine body. step_toward in
#     behavior.lua moves the bot's logical position in a straight
#     line. Used for soak regression in CI / headless mode.
#   * "mob"  — a real engine entity with A* pathfinding, GLB model,
#     gravity, and collision. Used when an admin joins to play
#     against the bots, or when running the mob-mode soak.
# All botmatch settings require sl_botmatch.enabled = true to take
# effect; mob_mode further requires the aaa_botmatch mod to be loaded
# with mob_player.lua (it is, by default).

# Master switch for the botmatch harness. When false, /sl_bots is
# still registered (so the admin can prep a pool) but no bots are
# spawned, no soak loop runs, and the arena isn't built.
sl_botmatch.enabled (Botmatch harness enabled) bool false

# Spawn each bot as a real engine entity with A* pathfinding
# (mods/game/aaa_botmatch/mob_player.lua). When false, bots are
# pure-Lua stubs that move in a straight line via set_pos — fine
# for headless soak but they never collide, never gravity-fall,
# and never block the admin's path. /sl_bots rejects with a clear
# error if this is false.
sl_botmatch.mob_mode (Botmatch mob mode (engine entities)) bool false

# How many bots the pool starts with (only consulted when enabled
# is true and the pool is empty). Bot names default to bot_alpha,
# bot_beta, bot_gamma, bot_delta, bot_epsilon, bot_zeta; the
# /sl_bots add / remove subcommands mutate the pool at runtime.
sl_botmatch.bots (Default bot count) int 4 0 6

# Distance between the two beacons in the auto-arena. Larger = more
