# Quarantined Server Node — Match Example (Draft V3)

Now let's imagine a match of this game with 5 players. This example iterates over existing systems (scavenging, crafting, the Resonance Meter, the Malware Horde, and the Impostor's Correction log) but applies the core rules of the simulation: **Observation never returns perfect information, and the visual style is 3D Cybernetic Neon.**

```
[System Log]: Insertion complete. 5 Operators aboard Quarantined Node Alpha.
[System Log]: Malware Resonance is at baseline. The containment perimeter is stable.

Operator A: I'm heading to the lower sector grid. We need scrap metal for the power armor set if we are going to survive a breach.
Operator B: I'll come with you. I have the Signal Scanner. 

*Operator A and Operator B descend via the maintenance elevator. They are visually identical neon wireframes against the black void.*

Operator B: Scanner shows clear. No corruption tags in a 24m radius.

*Operator A begins mining memory caches for scrap. They find 50 scrap metals and a loot crate containing 2 boots, 2 leggings, a jacket, and a helmet. They equip it.*

*Chat says that Beacon A's containment grid is under attack by the malware.*

Operator A: Beacon A is taking corrosion damage. Did anyone see who was up there?
Operator C (via DM to A): I saw D walking away from Beacon A right before the alert. 

*Operator A checks the shared Event Log. The log says Operator D was in the Armory sector, not near Beacon A.*

Operator A: The log says D was in the Armory. Someone is lying. 
Operator B: Or the Impostor used an illegal memory overwrite (Correction) to edit the log. 

*The background neon gridlines glitch and shift slightly. The Resonance Meter ticks up. A lie was just told, or a log was just forged, but the meter does not reveal WHO did it.*

Operator A: The Resonance just spiked. We are dragging the malware closer. 
Operator B: I'm sweeping the room again. 

*Operator B activates the Signal Scanner. The scanner screams—it detects a presence within 30 meters, but the bearing is fuzzy and the ping makes a loud digital noise.*

*From the dark corridor, a Dredger (a corrupted, lagging data-ghoul) leaps out, drawn by the scanner's noise.*

*Operator A uses their new power armor to punch the Dredger, dealing heavy damage.*
*Operator B is downed in the fight.*

*Operator A activates haste mode, draining stamina to finish the Dredger off, and rescues Operator B.*

Operator B: Thanks. The scanner drew it in. I'm going to find plastic scrap for a laser blaster. You protect the beacon.

*Operator B leaves. Operator A checks the Resonance Meter again. It is climbing faster now. Operator A is left alone, staring at the door, wondering if B's scanner actually malfunctioned, or if B intentionally called the Dredger to kill them.*

[System Log]: Resonance approaching critical threshold. 
```
